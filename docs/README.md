# プロジェクト「みえるーむ」の理解

「みえるーむ」は災害発生時における避難者動態の可視化および避難所運営を支援するツールです。このプロジェクトは以下の特徴を持っています：

## 概要

- 災害発生時に避難者および避難所の正確かつ迅速な状況把握を支援
- 東京都、区市町村、避難所、都民の各レベルでの情報共有と意思決定をサポート
- マイナンバーカードを利用した避難者情報の簡単な登録と管理
- Bluetooth Low Energy (BLE)を活用したオフラインでの情報送信

## 技術スタック

### フロントエンド

- フレームワーク: Remix (React)
- スタイリング: Tailwind CSS
- チャート: Recharts
- マップ: Leaflet/React-Leaflet
- UI コンポーネント: Radix UI

### バックエンド
- フレームワーク: FastAPI (Python)
- データベース: PostgreSQL (Supabase)
- ORM: SQLAlchemy
- API サーバー: Uvicorn

## アプリケーション構造

### フロントエンド (app/)

1. ルート構造:
  - / - トップページ
  - /tokyo - 東京都全体のダッシュボード
  - /tokyo/:city - 区市町村ごとのダッシュボード
  - /tokyo/:city/:shelter - 避難所ごとのダッシュボード
  - /tokyo/:city/:shelter/checkin - 避難所チェックイン画面

2. 主要コンポーネント:
  - 避難者状況の可視化（円グラフ）
  - 物資状況の可視化（棒グラフ）
  - 避難所マップ（Leaflet）
  - 避難者一覧テーブル（フィルタリング機能付き）

### バックエンド (api/)

1. サービス構造:
  - evacuee_service - 避難者情報管理
  - shelter_service - 避難所情報管理
  - supplies_service - 物資情報管理
  - ble_device_service - BLEデバイス情報管理（マイナンバーカード連携）
2. データモデル:
  - マイナンバーID、氏名、生年月日、性別、家族情報などを管理
  - 避難所の収容状況、物資の在庫状況などを管理

## 機能概要

1. 都民向け機能:
  - マイナンバーカードを利用した避難者情報の事前登録
  - 災害時のBLEを利用した避難所チェックイン
  - 家族の安否確認
2. 避難所運営向け機能:
  - 避難者の属性情報や特記事項のリアルタイム把握
  - 物資やスペースの割り当て管理
  - 避難者の入退室管理
3. 区市町村向け機能:
  - 避難所のキャパシティや状態のリアルタイム把握
  - 避難者の人数分布や安否状態の可視化
  - 物資の分布状態の把握
4. 東京都向け機能:
  - 東京都全体の避難者数や安否状態の可視化
  - 不足物資の把握と物資配分の最適化
  - 区市町村ごとの状況把握

このプロジェクトは、災害時の情報共有と意思決定を効率化し、限られたリソースで多くの避難者に対応するための支援ツールとして機能します。
特にオフラインでの情報送信機能は、災害時の通信インフラが不安定な状況でも利用可能な点が特徴です。
